Entry for the [Weirdest Job Title: Blind Judge Showdown](https://make.fun/bounty/u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922) bounty on make.fun.

## What it does

`main.py` writes a single invented job title to `entry.txt` inside the
`MAKEFUN_OUTPUT_DIR` directory (default: `output/`). The output is exactly
the title text with no trailing newline, ready for the blind-judge gate
(1–60 characters).

## Run

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose a different output directory.
